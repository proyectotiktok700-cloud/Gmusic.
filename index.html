INFO

Versión SoundCloud Edition.

Qué funciona:
• Reproducción integrada mediante reproductores oficiales de SoundCloud.
• Selecciones por artista en Inicio y Biblioteca.
• Diseño adaptable a móvil y ordenador.
• Búsqueda externa directa de artistas y canciones.

Qué falta para el catálogo completo:
La API oficial exige registrar una aplicación y obtener credenciales; actualmente SoundCloud indica que el acceso API requiere registro de aplicación y credenciales. No se ha añadido ninguna clave privada a esta versión. La reproducción personalizada/DJ también requiere una integración compatible y permisos de streaming.
